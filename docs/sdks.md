# SDKs

`@memtavi/sdk` (TypeScript) and `memtavi` (Python) are generated by Fern from
`packages/spec/openapi.yaml`. Fern owns the source; this repository owns the manifests.

## Why we own the manifests

Fern cloud generates the SDK source on our plan, but package metadata is gated behind a
verified/paid organization, and local generation is Enterprise-only. So `package.json`,
`tsconfig.json` and `pyproject.toml` live here by hand, and Fern writes only into:

- `sdks/typescript/src`
- `sdks/python/src/memtavi`

Never hand-edit either directory. Anything a user must read from the package belongs in the
manifest or in the package-root `README.md`.

## Regenerating

Run this in the same pull request as any change to `packages/spec/openapi.yaml`:

```bash
bun run sdk:generate
```

It runs both Fern groups with the pinned CLI (`fern-api@5.203.0`, using your existing
`~/.fern/token` login), copies `sdks/typescript/src/README.md` to the package root, then
rewrites `sdks/spec.sha256` with the sha256 of the spec bytes. Commit the regenerated source,
the package README and the hash together.

`bun run sdk:check` (also part of CI) fails when the hash no longer matches the spec, or when
`sdks/typescript/README.md` differs from the generated `sdks/typescript/src/README.md`. It does
not call Fern, so a stale hash or README fails the build before anything is downloaded.

`bun run test:sdk` builds the TypeScript package and runs both smoke suites, which stub HTTP
and never reach the network or a real API.

## TypeScript

Neither package is on a registry yet; these are the install commands once it is published.

```bash
bun add @memtavi/sdk
```

```ts
import { MemtaviApiClient } from "@memtavi/sdk";

const client = new MemtaviApiClient({
  apiKey: process.env.MEMTAVI_API_KEY,
  subjectId: "3f2f6f1a-9d4b-4c1e-8f5a-2b7c9d0e1f23",
  baseUrl: "http://localhost:3000",
});

const page = await client.brains.listBrains();
```

The package is ESM, has no runtime dependencies, and ships `dist/`.

## Python

```bash
pip install memtavi
```

```python
import os

from memtavi import MemtaviApi

client = MemtaviApi(
    api_key=os.environ["MEMTAVI_API_KEY"],
    subject_id="3f2f6f1a-9d4b-4c1e-8f5a-2b7c9d0e1f23",
    base_url="http://localhost:3000",
)

page = client.brains.list_brains()
```

Runtime dependencies are `httpx`, `pydantic` and `typing_extensions`.
